BroCoders — Finds USPSTF-aligned preventive care gaps for the patient in context and drafts patient-facing outreach to close them.

About our offerings: A clinician-assist A2A agent that uses a deterministic, evidence-grounded care-gap engine (via our MCP server) to identify overdue screening/monitoring (e.g., A1c, BP, colorectal screening, mammography) and produce copy-ready SMS/portal outreach at a patient-friendly reading level. All FHIR access and outreach drafting is delegated to the Care Gap Closer MCP server.
